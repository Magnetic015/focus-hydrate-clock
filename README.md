# 专注补水钟

一个把「番茄专注」和「定时喝水」合在一起的纯前端小工具：每专注完一轮，就提醒你起身喝一口水，帮你在长时间学习或写代码时既保持专注，又不忘补水。

## 功能

- **番茄计时**：可自定义专注、短休、长休时长以及「每几轮长休」，支持开始、暂停、跳过、重置。
- **补水目标**：按体重估算每日建议饮水量（约 30 ml/kg，限制在 1500~3500 ml），并平均分配到每次休息。
- **今日计划**：一键生成当天的节奏表，标出每轮专注与休息、每次建议喝多少水。
- **快速记录**：+100 / +200 / +300 ml 按钮记录喝水，进度条实时显示完成度。
- **提醒**：阶段切换时发出提示音，授权后还会弹出浏览器通知。
- **本地保存**：记录按日期存在浏览器 localStorage，不联网、不收集任何数据。

## 运行方式

无需安装依赖，任选一种：

1. 直接用浏览器打开 `index.html`；
2. 或在项目目录启动一个静态服务器后访问 <http://localhost:8080>：

```bash
python3 -m http.server 8080
# 或 npx http-server . -p 8080
```

## 测试

核心逻辑放在 `logic.js`（浏览器与 Node 通用），用 Node 自带测试框架验证：

```bash
npm test
```

## 目录结构

```
index.html   页面结构
style.css    样式
logic.js     纯逻辑：饮水目标、计划生成、时间格式化、当日汇总
app.js       界面交互与计时
test/        单元测试
```
